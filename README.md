# Codveda Technologies — Web Development Internship

Submissions for the Codveda Technologies Web Development Internship (August–September 2026),
covering all three difficulty levels with two completed tasks per level.

## 📁 Structure

```
codveda-web-dev-internship/
├── Level1-Basic-StaticSite-Portfolio/
│   ├── static-website/     # Task 1 — multi-page static site (Home / About / Contact)
│   └── portfolio/          # Task 2 — personal single-page portfolio
├── Level2-Intermediate-FlexboxGrid-Todo/
│   ├── flexbox-grid-layout/ # Task 1 — responsive layout with Flexbox + CSS Grid
│   └── todo-list-app/       # Task 2 — To-Do list app with localStorage persistence
└── Level3-Advanced-FullStack-CRUD-Auth/
    └── fullstack-task-manager/ # Task 1 + 2 combined — full-stack CRUD app with JWT auth
```

## ✅ Tasks completed

| Level | Task | Stack |
|-------|------|-------|
| 1 — Basic | Static multi-page website | HTML, CSS |
| 1 — Basic | Personal portfolio page | HTML, CSS |
| 2 — Intermediate | Responsive layout (Flexbox + Grid) | HTML, CSS |
| 2 — Intermediate | To-Do list app | HTML, CSS, JavaScript, localStorage |
| 3 — Advanced | Full-stack CRUD app | React, Node.js, Express, SQLite (node:sqlite) |
| 3 — Advanced | User authentication system | JWT, bcrypt |

Each folder is self-contained and runnable by opening `index.html` directly in a browser
(Levels 1 & 2), or via `npm install && npm run dev` (Level 3 — see its own README for full
setup instructions).
